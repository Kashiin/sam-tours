# HAVAS — сайт

Сайт турфирмы HAVAS: туры по Узбекистану и Центральной Азии. Работает на Node.js без сборки.

## Запуск

```bash
npm install
npm start
```

Адрес: http://127.0.0.1:4173. На Windows можно открыть `start.bat`.
Порт и адрес задаются переменными `PORT` и `HOST`.

## Заявки в Telegram

Формы отправляют заявку на `POST /api/inquiry`, а сервер пересылает её в Telegram.

1. Создайте бота у @BotFather и получите токен.
2. Напишите боту любое сообщение (или добавьте его в группу менеджеров).
3. Откройте `https://api.telegram.org/bot<TOKEN>/getUpdates` и возьмите `chat.id`.
4. Скопируйте `.env.example` в `.env` и заполните `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

Если Telegram не настроен или недоступен, посетитель видит, что заявка не отправлена.
Копия заявки сохраняется в браузере, и её можно отправить через WhatsApp.
Сервер ограничивает частоту отправки: не больше 5 заявок в минуту с одного адреса.

## Языки

Есть русский, узбекский (латиница), английский и немецкий. Переключатель находится в шапке.
Новый язык добавляется в список `languages` в `js/i18n.js` вместе с файлами `js/i18n/<код>.js` и `<код>.strings.js`.
Выбранный язык сохраняется в браузере, его также можно задать адресом `?lang=en`.

Страницы собираются на русском, затем тексты заменяются по словарям из `js/i18n/`:

- `uz.strings.js`, `en.strings.js`, `de.strings.js` — пары «русский текст → перевод», файлы генерируются;
- `uz.js`, `en.js`, `de.js` — шаблоны для текста с числами («8 из 12», «5 дней / 4 ночи»).

После изменения или добавления текста на русском:

```bash
npm run i18n:check     # сколько строк без перевода
npm run i18n:missing   # список в i18n-missing.json
```

Новые переводы записываются в файл строками `NNNN<TAB>перевод`, где NNNN — номер строки в списке `i18n-missing.json` для этого языка.
Перенос строки обозначается ` ⏎ `. Затем перевод добавляется в словарь:

```bash
node scripts/i18n-merge.js en translations-en.txt
```

## Структура

- `index.html` — оболочка страницы.
- `js/main.js` — точка входа: язык, глобальные обработчики, первый рендер.
- `js/router.js` — маршруты (hash), рендер страницы и обработчики форм и фильтров.
- `js/layout.js` — шапка с мега-меню, переключатель языка, подвал.
- `js/components.js` — карточки, формы, FAQ, галерея.
- `js/pages/` — страницы: `travel.js` (туры, направления, заявки), `company.js` (услуги, о компании, контакты), `legal.js` (документы).
- `js/data.js`, `js/data/` — города, туры, услуги, тексты исходного сайта и карта фотографий.
- `js/i18n.js`, `js/i18n/` — переключение языка и словари.
- `css/site.css` — все стили.
- `server.cjs` — HTTP-сервер: раздаёт статику и принимает заявки.
- `scripts/` — инструменты для переводов.
- `assets/` — фотографии, шрифты (Playfair Display, Golos Text), документы.

## Фотографии

Источники, авторы и лицензии собраны в `assets/photo-manifest.json` и на странице «Фотографии» (`/credits`).
Ключевые кадры взяты с Wikimedia Commons (CC0, CC BY-SA), остальные — с исходного сайта HAVAS.
Для фото с лицензией CC BY-SA обязательно указывать автора, поэтому страницу «Фотографии» удалять нельзя.
